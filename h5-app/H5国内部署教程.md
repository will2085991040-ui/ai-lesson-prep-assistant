# AI备课助手 H5 · 国内部署保姆级教程（含备案 + 域名 + 服务器）

> 写给第一次部署网站的纯新手。全程照着点，预计总花费：**域名 55-75 元/年 + 轻量服务器 99 元/年（首年）**，备案免费。
> 每一步都写了"点哪里、填什么、要等多久"。

---

## 〇、先看懂整体流程（30 秒）

```
你买一个域名（如 beike.cn）
      ↓
买一台腾讯云轻量服务器（99 元/年）——用途：备案的"落脚点" + 放网页文件
      ↓
域名实名 → 提交备案（免费，等 7-15 天）
      ↓
服务器装宝塔面板（免费）→ 建网站 → 上传 H5 网页 → 绑定域名
      ↓
微信里打开你的域名 → 成功 🎉
```

> 为什么要服务器？国内规则：**域名绑到国内服务器必须备案，备案必须有服务器**。这台 99 元的服务器顺便就当网页的家，一举两得。

## 第 1 步：买域名（腾讯云，55-75 元/年）

> 你已有腾讯云账号，按下面精确路径操作：

1. 打开 cloud.tencent.com 登录 → 顶部搜索框输入「**域名注册**」→ 进入域名注册页。
2. **先建实名模板**（重要！不实名域名买了也不能用）：页面左侧/顶部找「**信息模板**」→「新建模板」→ 模板类型选「**个人**」→ 填你的姓名、身份证号、手机、邮箱 → 提交实名（要上传身份证照片，审核约 1 天）。
3. 回到域名注册页 → 输入你想注册的名字（如 beike-ai，**建议 .com 后缀**）→ 点「查询」→ 挑「未注册」且便宜的（.com 首年约 55-75 元）→ 结算时「域名信息」选你刚建好的个人模板。
4. 支付完成。域名自动进入实名流程（用模板实名），1-3 天后状态变「已实名」即可继续备案。

## 第 2 步：买轻量服务器（腾讯云，99 元/年）

1. cloud.tencent.com → 搜索「**轻量应用服务器**」→ 点「立即选购」。
2. 选配置：
   - 地域：**上海**或**广州**（离你近）
   - 套餐：**2核2G** 那款（新用户价 99 元/年；老账号没这个价就在首页找「新用户专区/续费优惠」或换个新注册账号）
   - 镜像（最关键）：选「**宝塔 Linux 面板**」镜像
3. 购买 → 等 1-2 分钟开通 → 记下 **公网 IP**（形如 123.45.67.89）。
4. 顺手放行端口：服务器控制台 → 「防火墙」→ 确认已放行 **80、443、8888** 三个端口（宝塔镜像一般默认已放行）。

## 第 3 步：备案（免费，等 7-15 天，提前开始！）

> 备案期间网站不能开放，所以**这一步买完服务器立刻做**，边等备案边做第 4-6 步的准备。

1. 腾讯云控制台 → 顶部搜「**备案**」→ 进入备案小程序/页面。
2. 按引导填：主体信息（个人：你的姓名+身份证+手机号）、网站信息（域名、网站名称建议填「**备课助手**」这类朴实名称——带"AI"字样容易被要求说明用途而驳回，内容选「工具/其他」）。
3. 拍身份证、人脸核验 → 提交。
4. 腾讯云初审（1 天）→ 管局审核（约 7-15 天）→ 短信通知你备案号。
5. 通过后把**备案号**记下来，第 6 步要用。

## 第 4 步：准备好你的 H5 网页文件（等备案时做）

1. 打开 HBuilderX → 打开 `ai-lesson-prep-h5` 项目。
2. 先改网关地址：打开 `utils/config.js`，把 `GATEWAY_URL` 换成你自己的 h5gateway HTTP 触发地址（怎么拿到见《部署教程.md》第 1 步）。
3. 菜单 **发行 → 网站-H5手机版** → 完成后在项目目录找到：
   `unpackage/dist/build/h5` ← **这整个文件夹就是要上传的网页**。

## 第 5 步：登录宝塔面板（等备案时做）

1. 浏览器打开 `http://你的公网IP:8888`（宝塔默认端口）。
2. 第一次会要你设置用户名密码（腾讯云轻量的宝塔镜像，初始账号密码在控制台「防火墙/应用管理」里能看到，或点服务器详情里的「一键登录」）。
3. 登录后宝塔会弹「推荐安装套件」→ 选 **Nginx**（第一项）→ 极速安装（约 3 分钟装完）。
4. 装完在宝塔左侧点「**网站**」→「**添加站点**」：
   - 域名：填你的域名（不带 www，如 `beike-ai.com`，再点一下旁边的 www 会自动加一条）
   - PHP 版本：选「纯静态」或「不选」
   - 提交。

## 第 6 步：上传网页 + 绑定域名（备案通过后）

1. 宝塔 → 网站 → 你刚建的站点 → 点「**根目录**」→ 进去会看到 index.html 等默认文件。
2. 右上角「**上传**」→ 把你第 4 步的 `h5` 文件夹里的**所有文件**（index.html + static 等，直接全选）传上去（可先本地把 h5 文件夹打成一个 zip，宝塔支持上传 zip 后右键解压，更快）。
3. 回到你的**域名服务商**（阿里/腾讯）的域名控制台 → 解析设置 → 添加两条记录：
   - 主机记录 `@`，记录类型 `A`，记录值 `你的公网IP`
   - 主机记录 `www`，记录类型 `A`，记录值 `你的公网IP`
4. 等 2-10 分钟生效 → 浏览器打开 `http://你的域名` → **能看到 AI 备课助手首页 = 成功！**

## 第 7 步：免费开 HTTPS（锁头标志，微信内必须）

1. 宝塔 → 网站 → 你的站点 → 设置 → 「**SSL**」标签。
2. 选「Let's Encrypt」→ 勾选你的域名 → 点「申请」→ 自动签发（免费，90 天自动续期）。
3. 开启「强制 HTTPS」。
4. 再打开 `https://你的域名` → 地址栏出现 🔒 = 完成。

## 第 8 步：微信里测试 + 收尾

1. 手机微信 → 发给自己的文件传输助手 → 打开链接：
   - 能正常打开、能生成教案/课件 → 全部搞定 ✅
   - 提示"网页包含不安全内容" → 检查第 7 步 HTTPS。
2. 把域名填进 HBuilderX 发行时问的"网站标题/域名"，以后更新就是：**改代码 → 发行 → 宝塔重新上传覆盖**（30 秒的事）。
3. （可选）备案号按规定要展示：在 index.html 或页面底部加一行"京ICP备XXXXXXXX号"。

## 常见问题

| 问题 | 解决 |
| --- | --- |
| 打不开 IP:8888 | 腾讯云控制台 → 防火墙 → 放行 8888 和 80 和 443 端口 |
| 打开域名是宝塔默认页 | 没上传文件，或上传错目录（要传到站点根目录） |
| 备案被驳回 | 按驳回原因改（常见：网站名称带"AI"或"助手"需说明用途，改个朴实点的名称） |
| 不想等备案就想先用 | 过渡方案：Gitee Pages（国内快、免费、实名即可，无需备案），备案好了再切回自己域名 |
| 生成课件报网络错误 | config.js 的网关地址没改或没重新发行 |
| 续费提醒 | 域名 75 元/年、服务器首年 99 后可能恢复原价（约 400+/年），到期前腾讯云会提醒，可领券或换新用户价 |
