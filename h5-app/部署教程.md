# AI备课助手 H5/App 版 · 保姆级省钱部署教程

> 写给第一次做 App 和网页的你。目标：**花 0 元把 H5 网页上线，再用最便宜的方式打一个安卓 APK**。
> 本教程每一步都写清楚了"点哪里、填什么"，照着做即可。

---

## 一、先理解整体架构（30 秒）

```
微信小程序版（已有）──┐
                      ├──→ 同一套云函数后端（generateCourseware 等 20 个）
H5 网页版（本项目）───┤
安卓 App（本项目打包）┘
```

- H5 和 App 共用**同一个后端**（你的云开发），数据和积分互通。
- H5 通过一个「网关地址」（h5gateway 云函数）调用后端，所以**只需要改一处配置**。

---

## 二、第 1 步：给网关开"后门"（云开发控制台，5 分钟）

1. 打开微信开发者工具 → 顶部工具栏点 **云开发** 进入控制台。
2. 左侧菜单 → **云函数** → 找到 `h5gateway` → 点进去。
3. 找到 **「HTTP 触发」**（或叫"云接入 / HTTP 访问服务"）→ 点 **开启**。
4. 开启后会出现一个网址，形如：
   `https://你的环境ID.service.tcloudbase.com/h5gateway`
   **复制保存**，这就是你的网关地址。
5. 用记事本打开项目里的 `utils/config.js`，把 `YOUR-ENV-ID` 换成你自己的环境 ID（就是上面网址里 `https://` 和 `.service` 之间的那串），保存。

> 注意：`h5gateway` 云函数要先在开发者工具里右键「上传并部署：云端安装依赖」，控制台里才会出现它。另外把 `h5gateway` 的超时时间设为 60 秒。

---

## 三、第 2 步：安装 HBuilderX 并运行预览

1. 下载 **HBuilderX**（官方：https://www.dcloud.io/hbuilderx.html ）→ 选「标准版」→ 解压即用（绿色软件，不用安装）。
2. 打开 HBuilderX → 菜单 **文件 → 导入 → 从本地目录导入** → 选择 `ai-lesson-prep-h5` 这个文件夹。
3. 左侧项目树出现项目后，点菜单 **运行 → 运行到浏览器 → Chrome**。
4. 浏览器会自动打开本地预览页。这时候：
   - 首页能显示、生成教案/课件能出结果 → 网关配置成功 ✅
   - 提示"网络连接失败/网关配置" → 回第 1 步检查 config.js 的地址，或看浏览器按 F12 → Network 里请求报什么错。

---

## 四、第 3 步：发行 H5（得到可以部署的网页文件）

1. HBuilderX 菜单 **发行 → 网站-H5手机版**。
2. 弹窗里「网站标题」填 `AI备课助手`，域名先不填（以后有域名再填）。
3. 点「发行」→ 完成后会弹出一个文件夹：`ai-lesson-prep-h5/unpackage/dist/build/h5`。
   **这个文件夹里就是你的网页**（index.html + js/css 一堆文件）。

> manifest.json 已配好：hash 路由 + 相对路径 `./`，所以这个网页可以放在任何域名、任何子目录下运行，不用服务器配置。

---

## 五、第 4 步：0 元上线 H5（学生党最省钱方案）

托管平台就是把你的网页文件夹传到网上，让所有人能访问。三个免费方案选一个：

### 方案 A：Netlify（推荐，免费 + 免备案 + 最省事）
1. 打开 https://app.netlify.com → 用 GitHub 账号注册/登录（没有 GitHub 先花 3 分钟注册一个）。
2. 点 **Add new site → Deploy manually**（手动上传）。
3. 把第 3 步生成的 `h5` 文件夹**整个拖进去**。
4. 等几秒 → 它会给你一个网址 `https://xxxx.netlify.app`，**这就是你的网站**，微信里打开、发给学生都行。
5. 想换域名：Site settings → Change site name 改成好记的名字。

### 方案 B：GitHub Pages（免费，顺便学 Git）
1. 注册 github.com → 新建仓库 → 把 h5 文件夹里的文件传上去（网页端直接拖拽上传即可）。
2. 仓库 Settings → Pages → Source 选 main 分支根目录 → 保存。
3. 得到 `https://你的用户名.github.io/仓库名/` 网址。

### 方案 C：Gitee Pages（国内访问最快，但需要实名）
1. gitee.com 注册 + 实名认证 → 新建仓库上传 h5 文件。
2. 仓库 → 服务 → Gitee Pages → 启动。
3. 得到国内网址，打开速度最快（需要实名，免费）。

> 💡 **学生省钱要点**：全程 0 服务器费用；你的 AI 调用走云开发免费额度 + 方舟免费额度。唯一要注意的是方舟模型用超了会按量计费，自己控制好兑换码发放即可。

---

## 六、第 5 步：打包安卓 APK（最省钱方案）

### 方案 A（推荐）：HBuilderX 云打包（几分钟，按次几块钱）
1. HBuilderX 菜单 **发行 → 原生App-云打包**。
2. 选 Android → 证书用「公共测试证书」（免费，仅用于测试分发）→ 点打包。
3. 需要注册 DCloud 账号（免费），云打包按次计费（个人每次约 5-10 元，以官网为准）。
4. 打包完成后下载 APK 文件，发到手机安装即可（安装时允许"未知来源应用"）。

### 方案 B（0 元）：不装 App，用"添加到主屏幕"
1. 手机浏览器（Chrome/Edge/微信内置浏览器）打开你的 H5 网址。
2. 点浏览器菜单 → **添加到主屏幕**。
3. 桌面会出现一个图标，点开就是全屏网页，体验接近 App，**完全免费**。

### 方案 C（进阶免费）：本地离线打包
需要 Android Studio + 下载 uni-app 离线 SDK，流程复杂（半天起步），新手不推荐；等你玩熟了再折腾。

## 七、微信里访问的注意事项

- H5 网页在**非微信浏览器**打开时会弹「体验提示」，建议用户去微信里打开，或直接用小程序。
- 微信里打开 H5 后，点右上角「···」→ 收藏/浮窗，下次好找。
- 想要微信里"搜得到"：正式发布还是建议用**微信小程序**（你的小程序版已经做好，按《新手操作手册》提交审核即可，个人主体免费）。

---

## 八、常见问题

| 问题 | 解决 |
| --- | --- |
| 网页提示"网络连接失败" | config.js 的网关地址没改对，或 h5gateway 没开启 HTTP 触发 |
| 生成教案报"积分余额不足" | 网页版新用户送 200 分（首次打开自动注册）；用完了去充值中心输兑换码 |
| 图片/视频不显示 | 确认网关 tempUrls 正常；刷新重试 |
| 导出 PPTX 打不开 | 浏览器拦截了新窗口弹窗，允许弹窗后重试 |
| HBuilderX 运行报错 | 确认导入的是 ai-lesson-prep-h5 根目录（包含 manifest.json） |
| 云打包要钱吗 | 公共测试证书免费；云打包服务按次收费，约几块钱 |
| 微信里打开 H5 是白屏 | 换 https 托管（Netlify/GitHub Pages 都是 https） |
