# AI备课助手 · 新手操作手册（从零到上线）

> 写给第一次玩微信小程序的你。**每一步都照做，不懂的名词都有解释。**

---

## 第 0 步：先搞清楚 4 个东西

| 名词 | 是什么 | 你现在的状态 |
| --- | --- | --- |
| **微信开发者工具** | 在电脑上写小程序、模拟运行、上传代码的官方软件 | 还没装，第 1 步装 |
| **AppID** | 你的小程序的"身份证号" |
| **云开发** | 微信提供的"服务器"，不用自己买服务器，数据库和云函数都放这 | 还没开通，第 4 步开通 |
| **微信公众平台** | 网页版管理后台（改名字、提交审核、发布上线） | 网址 mp.weixin.qq.com |

> 前提：你的微信已经注册过小程序（拿到 AppID 说明注册过）。如果 AppID 不是用你自己的微信注册的，后面会卡在登录那一步，需要换成注册时用的那个微信。

---

## 第 1 步：安装微信开发者工具

1. 打开官网下载页：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 选 **稳定版 Stable Build** → 按你电脑系统选（Windows 选 64 位）→ 下载。
3. 双击安装，一路点「下一步」装完。
4. 打开软件 → 用**微信扫码登录**（扫的必须是注册这个小程序的那个微信）。

---

## 第 2 步：导入项目（就是你说的"选择文件之后"）

1. 软件打开后，如果问你要「小程序」还是「小游戏」，选 **小程序**。
2. 看到主界面后，点 **「导入项目」**（或加号 +）。
3. 弹窗里填三样：
   - **目录**：点旁边的文件夹图标 → 选中 `C:\Users\mine\Downloads\ai-lesson-prep-assistant` 这个文件夹（⚠️ 就是包含 README.md 的那个文件夹，**不要**选里面的 miniprogram 子文件夹）。
   - **AppID**：会自动带出 `wx1a1213e6a836a1cd`（项目里已经填好）。如果没带出来或提示不对，检查是不是登录微信不对。
   - **后端服务**：选「微信云开发」。
4. 点「导入」→ 第一次加载约 1 分钟。
5. 点顶部工具栏的 **「编译」** 按钮 → 左边手机模拟器里出现 App 界面（首页有 4 个快捷入口）。如果首页报几个红字错误，先别慌，这是因为云还没开通，做完第 4~6 步就好。

## 第 3 步：认识一下界面（30 秒）

- **模拟器**：左边那个手机画面，可以直接用鼠标点，就是"假手机"。
- **编辑器**：中间写代码的地方（你现在不用写）。
- **调试器**：下面/右边看报错日志的地方，出问题时把红字复制给 ChatGPT 看。
- **顶部工具栏**，你只需要认识 4 个按钮：
  - `编译`：刷新模拟器
  - `预览`：生成二维码，用手机真机打开
  - `上传`：把代码传到网上（发布前才用）
  - 一朵云图标的 **`云开发`**：打开云开发控制台
- **左侧文件树**最顶部有一个带云朵图标的 `cloudfunctions` 目录，里面是 11 个云函数（第 6 步部署它们）。

## 第 4 步：开通云开发（免费额度，别怕花钱）

1. 点工具栏的 **云开发** 按钮（云朵图标）。
2. 首次会提示开通 → 点 **「开通」** → 同意协议。
3. 创建环境：
   - 环境名称：随便填，比如 `ai-prep`。
   - 付费方式：选 **「按量付费」**（新用户每月有免费额度，个人开发测试基本够用，用超了才按量计费；具体政策看官方页：https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/billing/price.html ）。如果界面强制让你买套餐，选最便宜的那个。
4. 等 1 分钟左右环境创建完成，会自动进入「云开发控制台」（一个网页面板，数据库、云函数都在这里管）。
5. 因为你只建了 1 个环境，项目里 `CLOUD_ENV_ID` 留空就能用默认环境，**不用改任何代码**。

## 第 5 步：创建 13 个数据库集合

在云开发控制台 → 左侧菜单点 **「数据库」** → 点 **「+」** 创建集合，**逐个**创建下面 13 个（名字一个字母都不能差）：

```
lesson_plans    ppt_outlines    coursewares    exercises
analysis        api_logs        user_stats     users
orders          transactions    redeem_codes   textbooks
video_tasks
```

每个集合创建时/创建后，把权限设为 **「仅创建者可读写」**（在新版控制台里：数据库 → 选中集合 → 「权限设置」→ 选它）。

> 通俗解释：集合 = 数据库里的一张张"表格"，App 生成的教案、用户余额、积分流水分别存在不同的表格里。

## 第 6 步：部署 20 个云函数（把"大脑"传到云上）

1. 回到开发者工具主窗口。
2. 左侧文件树**最顶部**（云朵图标下）展开 `cloudfunctions`，里面是 20 个文件夹：
   `analyzeStudentProfile / exportPPTX / generateCloze / generateCourseware / generateExercises / generateImage / generateLectureScript / generateLessonPlan / generatePPTOutline / generateSlideImages / generateVariants / generateVideoTask / generateWords / getInspiration / getTextbooks / getUserStats / getWallet / login / queryVideoTask / redeemCode`
3. 对**每一个**文件夹：**右键 → 「上传并部署：云端安装依赖」** → 等左下角提示"上传成功"。
4. 20 个全部部署一遍（每个约 10~30 秒）。
5. ⚠️ **改超时时间**（不改会大概率失败）：云开发控制台 → 「云函数」→ 逐个点下面这些函数名 → 点「配置」→ **超时时间**：
   - `generateLessonPlan / generatePPTOutline / generateExercises / analyzeStudentProfile / getInspiration` → 改 **20 秒**
   - `generateCourseware / generateImage / generateSlideImages / generateLectureScript / generateCloze / generateVideoTask / queryVideoTask` → 改 **60 秒**
   - `generateWords / generateVariants / exportPPTX` → 改 **30 秒**
   - 保存。（其余函数不用改）

> 你的方舟 API Key 和三个模型接入点（DeepSeek 文本/豆包生图/豆包视频）已经写在对应 AI 函数的 `env.local.js` 里，会跟着一起传上去，所以**不需要**再去配置环境变量。
>
> ⚠️ **数据库注意**：视频任务用到 `video_tasks` 集合，请确保第 5 步已创建（如没有，去云开发控制台补建一个，权限「仅创建者可读写」）。

## 第 7 步：添加一个兑换码（充值用）

1. 云开发控制台 → 数据库 → 选中 `redeem_codes` 集合 → 点 **「添加记录」**。
2. 切换到「JSON 模式」（或手动加 3 个字段），填入：

```json
{ "code": "VIP2024", "credits": 600, "used": false }
```

3. 确定。以后想再发兑换码，就再来加一条（code 换成别的，used 保持 false）。

> 积分规则：新用户自动送 200 分；教案/学情各 30 分、AI 完整课件 40 分、课件单页配图 25 分/张、开场视频 120 分/个、导出 PPTX 20 分、说课稿/随堂挖空各 15 分、封面图 25 分、习题 20 分、课件大纲 15 分、单词表/变式题各 10 分。

## 第 8 步：第一次运行测试

1. 开发者工具点 **「编译」**。
2. 首页 → 点「智能备课」→ 学科选「语文」、年级选「三年级」、课题填「荷花」→ 点「✨ 生成完整教案」→ 等 10~30 秒 → 出现 8 个折叠模块，成功！
3. 再测积分：点「我的」→「积分余额」→「去充值」→ 兑换码输入 `VIP2024` →「立即兑换」→ 提示到账。
4. 想用**手机**试：点工具栏「预览」→ 用**同一个微信**扫码 → 手机里打开真实小程序测试。

> 真机预览打不开？大概率是扫码的微信和注册小程序的微信不是同一个，或该微信还不是"开发者"（个人小程序的管理员自动是开发者）。

## 第 9 步：发布前的 4 件准备工作（网页端）

浏览器打开 **mp.weixin.qq.com**，用管理员的微信扫码登录，然后：

1. **完善信息**：设置 → 基本设置 → 填小程序名称、头像、介绍（想好名字，一年能改的次数有限）。
2. **选类目**：个人主体可选的类目不多。教育类如果没有个人可选项，可以先选「工具 > 信息查询」之类个人能选的类目（审核不过再按提示调整）。
3. **用户隐私保护指引**：设置 → 服务内容声明 → 完善《用户隐私保护指引》→ 声明收集的信息勾选「用户信息（昵称头像）」。
4. **小程序备案**（工信部强制要求，不做无法上线）：设置 → 「小程序备案」→ 按提示提交（个人也能备案，一般 1~7 天）。

## 第 10 步：上传代码

1. 开发者工具点工具栏 **「上传」**。
2. 版本号填 `1.0.0`，备注填「首次提交」→ 确定 → 提示上传成功。

## 第 11 步：提交审核

1. mp.weixin.qq.com → 左侧「管理」→ **「版本管理」**。
2. 找到「开发版本」里的 1.0.0 → 点 **「提交审核」**。
3. 按提示填：功能页面可填 `pages/index/index`，审核备注可写"教师备课工具，AI 生成教案/课件/习题，含积分充值与兑换码功能"。
4. 提交后等审核（一般 1~7 天，个人工具类通常较快）。

## 第 12 步：发布上线 🎉

审核通过后 → 版本管理 → 找到「审核通过」的版本 → 点 **「发布」** → 选择全量发布 → 完成。之后任何人在微信里搜索你的小程序名字就能用。

以后要更新功能：改代码 → 编译测试 → 上传（版本号 1.0.1）→ 提交审核 → 发布，循环即可。

## 🆘 常见报错对照表

| 报错/现象 | 原因 | 解决 |
| --- | --- | --- |
| 导入时提示 AppID 不合法/不属于当前账号 | 登录的微信不对 | 换成注册小程序的那个微信扫码登录 |
| 点「云开发」是灰的/提示游客模式 | AppID 无效 | 检查 appid 是否填对 |
| 首页热门课题报错、生成按钮点了报"调用失败" | 云函数没部署 | 回第 6 步，把 11 个函数全部右键上传部署 |
| 提示「未配置环境变量」 | 函数里的 env.local.js 丢了 | 从项目文件夹把 env.local.js 复制回函数目录，重新部署该函数 |
| 提示「AI 返回内容格式异常」| 模型偶发抽风 | 点「重新生成」重试 |
| 提示 401 / invalid api key | 方舟 Key 失效 | 到 https://console.volcengine.com/ark 重新生成 Key，改 env.local.js 后重新部署 |
| 提示「模型不存在/endpoint」 | 接入点不对 | 文本函数应填 `ep-`，生图应填 `ep-`，到方舟确认接入点还在 |
| 生成 3~5 秒就失败"超时" | 函数超时没改 | 回第 6 步第 5 小步，改 20/60 秒 |
| 提示「积分余额不足」 | 积分用完 | 充值中心输入兑换码  |
| 手机扫码预览打不开 | 微信不是管理员/开发者 | 用注册小程序的微信扫码 |
| 审核被驳回 | 类目/描述/内容问题 | 按驳回理由修改后重新提交 |

> 出任何红字报错：把报错文字复制保存，方便排查。改完代码记得先点「编译」再测。
