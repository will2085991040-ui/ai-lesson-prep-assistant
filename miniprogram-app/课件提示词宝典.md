# 课件提示词宝典 —— AI 备课提示词 Skill

> 本宝典汇集了网络上教师社区验证过的高分 AI 课件提示词技巧（含千问英语教学 PPT 高分提示词公式、DeepSeek 教案技巧、7 种方法 35 实例等），并已固化进「AI备课助手」的课件生成引擎（`miniprogram/utils/prompt.js` 的 `buildCoursewarePrompt`）。老师也可以把下面的模板复制到任何 AI 工具里直接使用。

## 一、核心公式（所有提示词的地基）

> **角色设定 → 背景信息 → 明确任务 → 结构拆解 → 硬性约束 → 输出格式 → 迭代优化**

1. **角色设定**：给 AI 一个专业身份（特级教师/教研员/课件设计师），输出质量立刻上一个台阶。
2. **背景信息**：学科、年级、教材版本、课题、学情——信息越全，内容越贴合。
3. **结构拆解**：把"做课件"拆成环节（导入→新授→巩固→小结），AI 不会漏环节。
4. **硬性约束**：页数、每页要点数、每条字数、字号要求——约束越具体，越不用改。
5. **输出格式**：要求 JSON 或表格，方便复制进 PPT 工具。
6. **迭代优化**：第一版不满意，别重开——直接说"第 5 页太简单，加入一道中考真题"。

## 二、完整课件提示词模板（50 页级别，可直接用）

```
你是一位拥有二十年教龄的国家级特级教师，同时是专业课件设计师。
请为以下课题制作一份可直接用于课堂投屏的完整课件：
【学科】物理  【年级】八年级  【教材】人教版物理八年级上册
【课题】光的折射  【总页数】30页  【课件模板】探究式

设计规范：
1. 内容必须紧扣教材知识点与课程标准，知识点不遗漏、不超纲；
2. 按布鲁姆认知目标由浅入深编排：记忆→理解→应用→分析→评价→创造；
3. 每页都要有互动设计（提问/讨论/随堂练习），并在讲解词中写明师生互动话术；
4. 第1页为封面页，最后1页为「课堂小结+课后作业」页；
5. 每页内容要点2-4条，每条不超过30字，一页只聚焦一个知识点；
6. 讲解词为该页教师的授课话术，60-120字，具体可讲。

输出 JSON 数组：[{"title":"页标题","content":"要点","visual":"配图建议","animation":"动画建议","speakerNotes":"讲解词"}]
```

## 三、教案提示词模板

```
你是一位资深教研员。请为《课题》写一份完整教案（学科/年级/教材/课时/课型/学情/风格）。
输出 JSON：title/textbookAnalysis/studentAnalysis/objectives(三维目标数组)/keyPoints/preparation/
process(每环节含教师活动/学生活动/设计意图)/boardDesign/reflection。
教学过程至少包含导入、新授、巩固、小结四个环节；目标要符合课程标准。
```

## 四、其他场景模板

**分层习题**：三层各 3 题（基础巩固/能力提升/拓展创新），每题含 options/answer/analysis，解析讲思路不给结论。
**学情诊断**：输出 5 维度雷达图分值 + 薄弱点（≤3条）+ 三层教学建议。
**单词表**：输出 word/phonetic/meaning/example/exampleCn，例句 ≤12 词，难度匹配年级。
**错题变式**：3 道变式（同难度→稍难→综合），换数字/换情境/换问法，保留考点。

## 五、进阶技巧（教师社区验证）

1. **布鲁姆分层**：明确要求"由浅入深"，AI 会自动把"知道"类内容放前面、"创造"类任务放后面。
2. **互动话术**：要求 AI 在讲解词里写"怎么问、学生可能怎么答、教师如何回应"，课件就从"念 PPT"变成"真上课"。
3. **教材锚定**：写清教材版本（人教版/沪科版/北师大版…），AI 会按该版本的章节顺序和例题风格出内容。
4. **模板化风格**：探究式/情境导入/大单元/项目式/复习课——同一课题换模板，得到完全不同思路的课件。
5. **few-shot 示例**：拿不准输出质量时，给 AI 一页"范例"，再让它照格式生成。
6. **迭代打磨**：把"不满意的地方"当新指令发回去，比重新生成更省积分。
