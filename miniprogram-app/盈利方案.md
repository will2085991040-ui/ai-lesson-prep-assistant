## 一、先回答两个关键问题

### Q1：不用云服务器吗？
**当前阶段：完全不用。** 你的架构是"微信云开发后端 + 免费静态托管"，没有任何服务器月租：
- 后端：微信云开发按量付费（个人用量在免费额度内 = 0 元）
- H5 托管：Netlify / GitHub Pages / Gitee Pages = 0 元
- 小程序：微信平台托管 = 0 元

**赚钱之后**（月流水过千后）才建议加：
| 项目 | 用途 | 成本 |
| --- | --- | --- |
| 轻量云服务器（腾讯/阿里新人价） | 可选，做官网/落地页/备案接入 | 约 99 元/年 |
| 国内 CDN/OSS | H5 国内加速 | 约 5-20 元/月（量小可省） |
| 域名 .com/.cn | 品牌信任 + 海外访问 | 约 55-75 元/年 |

### Q2：不用域名吗？
- **微信小程序**：不需要域名（平台内运行）。
- **H5 国内运营**：需要域名 + ICP 备案（备案免费，但要先有国内接入商，用上面的轻量服务器即可）。
- **H5 海外运营**：海外域名即可（Namecheap/Cloudflare 约 $10/年），**无需备案**。

## 三、国内盈利方案（4 条路，按投入递进）

### 🛣️ 路径 1（0 元）：流量主广告（被动收入）
- 条件：小程序**累计独立访客 ≥ 1000**（个人主体也能开通，见[流量主开通指南](https://www.chaoxunxing.com/news/9118.html)）。
- 做法：在小程序里加激励视频广告位（"看广告送 50 积分"），比 banner 收益高 5-10 倍。
- 预期：日活 100 人 ≈ 每月几十到几百元（教育类 eCPM 不错）。

### 🛣️ 路径 2（0 元）：第三方平台卖兑换码/会员卡（个人主体合法通道）
个人主体开不了微信支付，但可以在这些平台收款（都支持个人创作者）：
- **爱发电**（afdian.net）：最推荐，支持微信/支付宝收款，服务费约 5%。
- **知识星球**：社群 + 会员制，适合做"教师备课群"。
- **小报童**：专栏订阅。

玩法：平台上架「月卡 19.9 元 / 年卡 199 元」→ 购买后自动/手动发放**兑换码** → 用户在充值中心兑换（你的 `redeem_codes` 体系已就绪）。

### 🛣️ 路径 3（约 300 元/年）：个体工商户 + 微信支付（真正的收入引擎）
1. 免费注册**个体工商户**营业执照（网上办理或代办 100-500 元）。
2. 把小程序主体从个人变更为个体户 → 微信认证 **300 元/年**。
3. 开通**微信支付**（个体工商户支持，费率 **0.6%**）。
4. 站内直接卖积分/会员（你的充值中心只需把"兑换码"按钮换成"微信支付"下单，后端 `orders` 集合已预留）。

⚠️ 类目选「**工具-效率**」而不是「教育-在线教育」（后者要办学资质）；审核材料里突出"教师效率工具"属性。

### 🛣️ 路径 4：B2B 学校/机构版（利润最高）
- 产品：`学校版 999 元/年/校`（50 个教师账号、全校教研包共享、校本教材导入）。
- 打法：先免费送 3 所学校试用 → 收集好评 → 卖给周边培训机构/私立学校。
- 你的「知识库 + 教材库」就是天然的企业功能基础。

## 四、海外盈利方案

### 基础成本
| 项目 | 成本 |
| --- | --- |
| 海外域名 | ~$10-12/年 |
| Netlify/Vercel 托管 | 0 元 |
| Google Play 开发者账号 | $25 一次性 |
| Apple 开发者账号 | $99/年 |

### 收款通道（关键，按对中国创作者友好度排序）
1. **Gumroad**：个人可注册，**PayPal 提现到中国可用**，费率约 10%+PayPal 手续费；卖订阅/数字商品都行（[费率对比参考](https://quasa.io/media/gumroad-vs-lemon-squeezy-which-platform-costs-digital-product-sellers-less)）。
2. **Lemon Squeezy**：Merchant of Record（帮你处理各国税），PayPal 提现。
3. **Stripe**：中国个人**不能直接开**，需要海外主体（英国公司注册约 £100-200，见[英国公司注册指南](https://www.ukcompany.cn/news/indie-developer-uk-company-registration-guide-2026)）——月流水超 $1000 再考虑。

### 产品本地化清单
1. 英文界面 + 提示词（你的 prompt.js 输出英文课件即可，DeepSeek 支持）。
2. 目标用户：海外 K-12 教师、家教（TpT Teachers Pay Teachers 社区引流）。
3. 对标定价：MagicSchool AI 免费增值、Diffit $14.99/月、Gamma $8/月 → 你定 **Teacher $9.9/月 或 $79/年**，School $199/年。
4. 合规：不收集学生数据（避开 COPPA/FERPA 红线）、隐私政策页、GDPR 同意弹窗。
